# eq-valent · Startseite

Statische Startseite für eq-valent (Entwurf „Tiefgang v4“). Reines HTML, CSS und JavaScript, ohne Build-Schritt und ohne externe Bibliotheken.

- `index.html` – die Seite
- `css/style.css` – alle Stile
- `js/main.js`, `js/ball.js`, `js/tilde.js` – Verhalten, Fußball im Spielraum, Glaskugel bei „Haltung“
- `assets/` – Bilder (WebP) und lokal eingebundene Schriften

Zum Ansehen den Ordner über einen lokalen Webserver öffnen, zum Beispiel `python3 -m http.server`. Direkt per Doppelklick geöffnet fehlen die WebGL-Effekte.
